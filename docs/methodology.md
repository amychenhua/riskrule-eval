# 方法说明

## 1. 统一口径

每个场景都把“规则命中一条记录”看成一次处置动作，结果只有四种：

| | 实际是正样本 | 实际是负样本 |
|---|---|---|
| 规则命中 | TP：处置对了，获得避免损失 | FP：处置错了，付出机会成本 |
| 规则未命中 | FN：漏掉了 | TN：正确放行 |

```
净收益 = Σ_TP 避免损失 − Σ_FP 机会成本 − Σ_命中 运营成本
```

避免损失、机会成本、运营成本是逐条记录计算的，计算式由场景 YAML 的 `value_model` 给出，可以引用数据列和参数。引擎只在 TP 上累加避免损失，只在 FP 上累加机会成本，所以这两列对每条记录都可以填估计值。

基础指标：

- 命中率 = 命中量 ÷ 样本量
- 召回率 = TP ÷ 正样本数
- 精确率 = TP ÷ 命中量
- 误伤率 = FP ÷ 负样本数
- 提升度 = 精确率 ÷ 总体正样本率

## 2. 八类分析

**单规则评估。** 每条规则单独算上面的全部指标。提升度低于 1 说明命中群体比总体更安全，规则方向可能有问题。规则重叠表给出“规则 A 命中的样本里有多少同时被规则 B 命中”。

**策略对比。** 一套策略是若干规则的并集，任一命中即处置。按策略文件里的顺序取前两套做对比，第一套是基准。

**边际贡献（去一法）。** 对策略里的每条规则，算剔除它之后的净收益：

```
边际贡献 = 全量净收益 − 剔除该规则后的净收益
```

边际贡献为负，说明这条规则独占命中的那部分样本里，误伤成本高于避免的损失。“独占命中量”是只有这条规则命中的样本数，独占量很小的规则基本是冗余的。

**Swap 分析。** 把样本按两套策略的结果分成四组。Swap-in（基准放行、新策略命中）的净收益影响是该组的净收益，Swap-out（基准命中、新策略放行）的影响是该组净收益的相反数。两者之和必须等于两套策略净收益之差，报告里会打印对账差额。方向合理的标志是 Swap-in 的正样本率明显高于总体，Swap-out 不高于总体。

**阈值扫描。** 对一个连续字段取一串阈值，每个阈值当作一条单独的规则评估，净收益最高的点为最优。最优点落在扫描范围边界上时，应扩大范围重扫。

**决策矩阵。** 两个条件“或”的关系，对两组阈值的每个组合算净收益。用来看两个杠杆之间是否互相替代。

**敏感性分析。** 避免损失和机会成本各乘 0.7、1、1.3，得到 3×3 的“两套策略净收益之差”。九个格子同号，说明结论不依赖这两项的估计精度。另有一张表给出运营成本乘 0、0.5、1、2、5 时的结果。

**区分度与稳定性。** 对扫描字段计算 KS、AUC 和洛伦兹曲线（按风险从高到低排序的累计正样本占比）。按时间字段分月统计命中率，并计算监控字段各月相对首月的 PSI：

```
PSI = Σ (监控占比 − 基准占比) × ln(监控占比 ÷ 基准占比)
```

小于 0.1 稳定，0.1 到 0.25 加强观察，大于 0.25 需重评阈值。占比为 0 的分箱用 0.0001 代替。

## 3. 六个场景的取值模型为什么这样定

**反洗钱。** 反洗钱规则的产出是可疑交易报告，没有直接的财务收益。模型给每条有效预警一个“合规价值”（可以理解为避免处罚和声誉损失的期望值），再加上能拦截的涉案资金比例。成本主要是人工甄别，每条预警都要付。因此这个场景里精确率（预警有效率）直接决定净收益，净收益本身应作为辅助口径。

**反电诈。** 拦截一笔诈骗交易，避免的是客户的资金损失中未能追回的部分。误拦截的代价是客户体验和投诉，外加少量手续费损失。

**贷前反欺诈。** 欺诈申请一旦放款，损失接近全额，用“申请金额 × 欺诈损失率”估算。误拒损失该笔申请的预计利润。

**贷前审批。** 模板直接要求填“预计损失金额”（违约敞口 × 违约损失率）和“预计利润”，因为这两项各行的测算口径差异大，由使用方自行计算更准确。

**贷中调额。** 降额只能阻止坏客户继续动用未用额度，已经用掉的余额救不回来。避免损失 = 拟下调额度 × 信用转换系数（坏客户违约前本会动用的比例）× 违约损失率。对好客户降额会减少用信收入并增加流失。示例数据里“高使用率”规则提升度很高但净收益为负，原因正是这些账户几乎没有未用额度可降。

**贷后预警。** 预警本身不减少违约，价值在于提前处置比事后催收多挽回一部分余额。这个“多挽回的比例”必须用对照组估计。误预警会打扰正常客户并增加流失。

## 4. 没有做的事

- **拒绝推断。** 被拒绝或被拦截的样本没有结果标签，工具不做外推。使用方需要自己准备带标签的评估样本，并意识到只用通过样本评估会偏乐观。
- **时间价值和客户生命周期价值。** 净收益是单期口径。需要多期折现时，把折现后的金额填进利润和损失字段即可。
- **规则自动搜索。** 工具评估给定的规则和阈值，不自动生成规则。阈值扫描和决策矩阵是在给定字段上的穷举。
- **统计显著性。** 报告不给置信区间。正样本少于 100 个时会给出警告，建议用自助法重抽样评估结论的稳定性。
